# FinBooksOS

Commercia Route / Product for All.

A design-led financial workspace for independent professionals and service businesses, where client work naturally becomes money.

FinBooksOS is a separate product and repository from madebykraman/minimical.finance. Minimical Finance is reference-only and must not be modified as part of FinBooksOS work.

The attached Invoice Product Intelligence Report is the governing product specification. Phase 0 establishes semantic tokens, restrained operations UI, responsive shell and dashboard hierarchy before domain modules expand.
